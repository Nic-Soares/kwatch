# T17 · Opção 2: buscar leitura por ID (PDF p13, p14)

Onde houver □, a resposta ainda falta. Responda antes de escrever no `main.c`. Os nomes são os do seu `main.c` (`nUnidade`).

## 0. Definição

Com as suas palavras, em 1 ou 2 frases: o que a opção 2 pede, o que faz e o que mostra quando acha e quando não acha.
Consulte: [Menu e segundos menus](referencia.md#menu-e-segundos-menus) ("Segundo menu da opção 2"), [Saídas de cada opção](referencia.md#saídas-de-cada-opção) ("Opção 2") e o [conceito 40](../conceitos.md#40-opção-2-busca-e-o-ordenado-antes-da-binária).

Minha definição: a segunda é para busca de leitura por ID, ao escolher, ela vai perguntar o ID procurado, e em seguida o método de busca; se for a binária e ainda não ordenou, ordena antes. Caso o ID não exista, ira responder: Leiura nao encontrada.

## 1. A ordem do que acontece

PDF p13: primeiro pede o ID (`Digite o ID da leitura:`), depois mostra o submenu de busca. A 1ª linha é o modelo.
Consulte: [Menu e segundos menus](referencia.md#menu-e-segundos-menus) e a sua T16 (o submenu da opção 1 é igual na forma).

| Passo | O que o programa faz |
|---|---|
| 1 | imprime `Digite o ID da leitura:` e lê o ID numa variável `idBusca` |
| 2 | pergunta qual o algoritmo de busca será usado |
| 3 | lê a escolha do submenu (1 = linear, 2 = binária); se for a binária e `ordenado == 0`, ordena os 5 arrays e faz `ordenado = 1` |
| 4 | chama a busca escolhida e guarda a posição em `pos` |
| 5 | se `pos != -1`, imprime as 7 linhas da leitura; senão, imprime `Leiura nao encontrada.` |

## 2. Qual chamada para cada escolha

As duas buscas procuram `idBusca` dentro de `ids` e devolvem a **posição** (ou -1).
Consulte: o `kwatch.h` e a sua T04 e T05.

| Escolha no submenu | Chamada |
|---|---|
| 1 | `pos = buscaLinear(ids, n, idBusca);` |
| 2 | `pos = buscaBinaria(ids, n, idBusca);` |

## 3. A binária precisa de `ids` ordenado

PDF p13: "se for a binária e ainda não ordenou, ordena antes". Que variável da T16 diz se já ordenou? O que o programa faz se ela valer `0`, e o que muda nela depois?
Consulte: o [conceito 40](../conceitos.md#40-opção-2-busca-e-o-ordenado-antes-da-binária) e o [conceito 39](../conceitos.md#39-opção-1-submenu-uma-vez-e-a-descrição-pelo-catálogo).

Variável: `ordenado`
Se valer 0: ordena os 5 arrays antes da busca (ex.: `quickSortLeituraPorId(ids, unidadeIds, meses, anos, consumos, 0, n - 1);`), porque a binária só funciona com `ids` em ordem. O PDF não diz qual ordenação usar.
Depois: `ordenado = 1`, então a opção 1 não pergunta mais o algoritmo.

## 4. Achou: as 7 linhas da saída

Com `pos = 2` (leitura de ID 3 depois de ordenar), complete o que vai em cada `printf`. A 1ª e a 2ª linhas são o modelo.
Consulte: [Saídas de cada opção](referencia.md#saídas-de-cada-opção) ("Opção 2") e o conceito 39 ("A descrição").

| Linha impressa | Variável que entra |
|---|---|
| `Leitura encontrada:` | nenhuma |
| `ID Leitura: 3` | `ids[pos]` |
| `Unidade: 101` | `unidadeIds[pos]` |
| `Descricao: Laboratorio de Informatica` | `descricoes[posDesc]`, com `posDesc = buscaLinear(unidadeIdsCatalogo, nUnidade, unidadeIds[pos]);` |
| `Mes: 2` | `meses[pos]` |
| `Ano: 2026` | `anos[pos]` |
| `Consumo: 310.20 kWh` | `consumos[pos]`, com `%.2f` e ` kWh` no texto |

## 5. Não achou

Quanto a busca devolve quando o ID não existe, e qual `if` separa os dois casos? A mensagem do PDF é `Leiura nao encontrada.` (dúvida D5: provisório, reproduzir igual ao PDF).
Consulte: [Retornos especiais](referencia.md#retornos-especiais) e [Saídas de cada opção](referencia.md#saídas-de-cada-opção).

O `if`: `if (pos != -1) { /* imprime as 7 linhas */ } else { printf("Leiura nao encontrada.\n"); }`
