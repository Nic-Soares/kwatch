## 3. Onde fica o `return -1`

Abaixo, duas versões. Só uma está certa. Diga qual, e o que a errada devolve procurando o ID 3 na tabela da seção 1.
Consulte: o [conceito 26](../conceitos.md#26-busca-linear-achei-e-o--1-depois-do-laço), "Cuidado".

Versão A:

```
for (i = 0; i < n; i++) {
  if (ids[i] == idProcurado) return i;
  else return -1;
}
```

Versão B:

```
for (i = 0; i < n; i++) {
  if (ids[i] == idProcurado) return i;
}
return -1;
```

A certa é: B
A errada devolve, procurando o 3: -1, porque no primeiro elemento (i = 0, cujo ID é 1), o if dá falso e o else return -1 executa imediatamente na primeira volta, encerrando a função antes de testar a segunda posição onde o ID 3 realmente está.
