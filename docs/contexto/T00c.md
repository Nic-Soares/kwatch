## 2. Valores especiais

Consulte: [Retornos especiais](referencia.md#retornos-especiais).

| Função | Quando devolve o valor especial | O que devolve |
|---|---|---|
| `carregarLeituras` | em caso de erro ao abrir o arquivo | -1 |
| `carregarUnidades` | em caso de erro ao abrir o arquivo | -1 |
| `buscaLinear` | caso não encontrado | -1 |
| `buscaBinaria` | caso não encontrado | -1 |
| `encontrarUnidadeMaiorConsumo` | quando duas ou mais unidades empatam no maior consumo | O ID da unidade com maior consumo (em caso de empate, retorna o menor ID entre as unidades empatadas) |

Por que -1, e não 0, para "não encontrado"? Porque o 0 é um índice válido (representa a primeira posição de um vetor ou array), enquanto o -1 é um valor sentinela utilizado para indicar um erro ou que o elemento não foi encontrado.
Consulte: [Termos](referencia.md#termos), linha "posição". □

## 3. `inicio` e `fim` no quick e no merge

Consulte: [Assinaturas das 12 funções](referencia.md#assinaturas-das-12-funções), último parágrafo, e a tabela `i | ids[i]` em [Dados do exemplo do PDF](referencia.md#dados-do-exemplo-do-pdf).

Com 5 leituras (posições 0 a 4), quanto valem `inicio` e `fim` na primeira chamada? inicio = 0 e fim = 4

E com `n` leituras, em geral? `inicio` = 0, `fim` = n - 1
